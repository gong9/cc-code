# gong-code

终端 AI 编程助手。

## 安装

**1. 先安装 [Bun](https://bun.sh)**

```bash
# macOS / Linux
curl -fsSL https://bun.sh/install | bash
```

> Windows 用户请参考 [Bun 官方安装指南](https://bun.sh/docs/installation)

**2. 安装 gong-code**

```bash
bun install -g gong-code
```

## 使用

```bash
gong-code
```

首次运行会引导你选择模型和配置 API Key。
